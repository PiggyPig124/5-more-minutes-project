## 已整合功能与入口

| 功能 | 应用入口 | 整合结果 |
| --- | --- | --- |
| 访客会话 | 登录页的访客入口 | 保留原实现，30 分钟闲置过期，结束后清除；不创建数据库账号或长期记忆 |
| 模型维护记忆、纠正、遗忘、故事 | 聊天和记忆库 | 保留原授权、证据校验、版本及删除清理机制 |
| 家庭授权、照顾事项、家庭消息 | 家庭区和首页 | 保留原权限和重试机制；安全求助使用同一家庭消息通道 |
| 真人群聊 | 家庭区的群聊入口 | 保留 WebSocket、邀请和成员权限；私人 AI 对话不进入群聊 |
| 广东话语音输入 | 私人聊天输入框的麦克风 | Hamza 的装置/浏览器识别，首次说明后启用，文字进入可编辑草稿；不会自动发送 |
| 本机提醒 | 账号菜单的本机提醒 | Android 用户自行启用，每日/每周问候、任务到期提醒、21:00–09:00 安静时段、成功聊天后延后问候 |
| 云端问候和通知 | 顶部收件匣按钮、账号菜单的关怀设置 | 补齐后端设置、暂停、略过今天、检查是否到期、收件匣状态操作；服务器每分钟检查一次 |
| 风险干预 | 私人聊天和指定支援 | 风险匹配后跳过模型及记忆检索，记录私有事件；求助须确认联系人和内容，不自动通知家人 |
| 社区来源搜索和技能确认 | 社区主页 | 保留原有来源状态、技能确认和记忆授权；来源适配器的默认禁用配置保持有效 |
| 活动目录和兴趣 | 社区页的活动目录按钮 | 接入 Hamza 的地区/兴趣筛选、推荐、表示兴趣与撤回；中英文筛选使用一致的数据键 |
| 防骗指南、核实步骤、官方联系和历史 | 帮助页的防骗入口 | 接入 Hamza 的搜索、Verify/Pause/Protect 和私有查看记录 |

## 兼容处理

1. 两个社区实现使用不同接口：来源搜索保留 `/community/...`，活动目录移到 `/community/catalog/...`，避免同名路由和模型冲突。
2. 修复活动和防骗 ORM 列表字段的 JSON 类型、`SafetyEvent.trigger_message_id` 写入，以及缺失的云端关怀 API。
3. 云端偏好使用新增 `care_preferences` 表，通知使用新增 `care_notifications` 表；原有账号、聊天、记忆、家庭及任务表保留。已有数据库启动时会创建新增表。
4. 目录推荐仅在记忆授权有效时读取当前有效的记忆。技能必须另外确认；未确认技能、已撤回、已替换及已删除记忆不会参与技能匹配。关闭授权后，迟到的客户端推荐响应也会丢弃。
5. 云端问候遵守每日/每周、时间、安静时段、暂停、略过和当天已聊天/已问候限制。定时器和手动检查共用逻辑及进程锁；模型回复期间更改暂停设置会阻止发送。
6. 家庭回复通知和照顾者任务提醒在每次读取时重新检查家庭授权。安全求助保留明确确认及幂等重试。防骗记录不能引用他人的私人会话。
7. 记忆删除会清理引用它的云端问候。收件匣从原消息读取正文，避免残留另一份被遗忘的记忆。
8. Hamza 的种子活动仅链接机构首页，无法证明具体活动时间、费用和地点，已标为未核实示例；仅在 `DEMO_MODE=true` 时供试用。正式模式只展示经过批准的目录记录。

## 验证

本次验证使用本机 SQLite、确定性聊天模式及模拟语音供应商，不使用真实用户数据。

- 后端：170 项完整 pytest 回归通过，覆盖原有功能、群聊和新增模块。
- Flutter：静态分析无问题，75 项单元和界面回归通过；3 项真实 HTTP 测试在普通回归中跳过，另行显式启用后全部通过。
- 实际 HTTP：Flutter 客户端连接整合后的 FastAPI，账号/家庭/记忆流程及新增关怀、目录、防骗、安全事件 3 项端到端测试通过。
- Android：debug APK 构建通过，输出 `app/build/app/outputs/flutter-apk/app-debug.apk`。
- Web：JavaScript 网页构建通过，输出 `app/build/web`。没有启用 WebAssembly；原有 secure-storage 插件仍依赖浏览器 JS API。

关键新增回归位于 `backend/tests/test_hamza_integration.py`、`app/test/catalog_widget_test.dart`、`app/test/catalog_consent_test.dart` 和 `app/test/hamza_live_api_test.dart`。

## 使用与运行范围

- 后端和 Flutter 的启动方法沿用 README。演示活动目录需要设置 `DEMO_MODE=true`。
- 本机系统通知目前仅支持 Android；网页版提供语音草稿与应用内云端收件匣，不提供后台系统通知。
- 云端提醒只写入应用内消息/收件匣，不是推送。后端运行时才执行排程，设置按香港时间解释。本次内置排程采用单进程锁，部署请使用一个 API worker；多 worker 需要单独的调度工作进程及跨进程协调。
- 语音按钮使用装置或浏览器服务，实际广东话识别、麦克风权限和真实设备通知送达仍需在目标手机验证。构建和模拟测试不能证明这些真实设备行为。
- 可选的 `/speech/transcribe` 是独立的腾讯音频上传接口，当前 Flutter 按钮不调用它。需要安装 `backend/requirements-asr.txt` 并设置 `TENCENT_ASR_SECRET_ID` 和 `TENCENT_ASR_SECRET_KEY`；每次上传须明确授权，缺少配置返回 503，不返回虚构转录。
- 本次真实 HTTP 测试采用 demo 聊天；外部模型和腾讯服务的生产调用没有用真实凭据验证。
