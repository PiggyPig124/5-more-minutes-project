## 现有基础与主要差距

代码已有：长者／照顾者账户、家庭邀请和撤销、私人文字聊天、记忆确认／修改／删除／暂停、私人故事与选择分享、家庭留言、共享任务、六条官方资源记录、繁体中文／英文界面。

主要差距：登录阻挡初次对话；长期记忆没有默认关闭的整体授权；候选记忆现有持久化机制与“Save 前不保存”有冲突；长者导航是 Home／Chat／Tasks／Family；缺少 Community、确认技能及机会匹配；Settings 主要只有语言；官方 Answer Card、帮助转介、完整连接拒绝／阻止与新版记忆类别仍需补齐。默认聊天适配器仍是明确标识的演示，不能据此宣称完成真实 AI 理解。

## 社区搜索方向更新

用户明确要求由 agent 自主搜索部分社区网站，不再让人工逐条收集和维护活动库。正在由 GPT-6-luna 的 `live_community_search` 和 `community_search_ui` 实现：从限定机构网站自动读取公开活动／义工信息，解析来源与日期，过滤过期内容，按一般兴趣主题和地区查询，并展示实时获取、缓存或来源不可用的状态。缓存只用于减少重复请求和保留获取时间；缓存不是人工录入的活动目录。

个性化搜索必须先获得记忆授权和技能确认，仅转换成一般主题词；私人经历、身份、完整记忆不发给机构网站。参加课程与贡献义工机会分别标注。检索结果不等于报名成功、仍有名额或符合资格；原始来源和未确认条件必须可见。外发联系及报名仍由用户决定。

运行时已验证可以公开读取香港基督教培道联爱会活动页面和赛马会众心行善平台公开机会页；聖雅各福群会活动搜索和照顾者资讯网在本轮直接请求中返回 403，不能宣称已成功接入。实际实现与验证结果另行记录。

来源条款复核：赛马会众心行善平台的使用条款限制网页抓取，现有技术实现不等于得到使用授权；HKCMIS 的自动再利用许可亦待确认。默认应用已停用两站适配器，启用前仍需完成来源许可审查，方案见 `ECHO_DEFERRED_FEATURES_FEASIBILITY_ZH.md`。

## 暂缓与需要团队输入的事项

- 粤语 ASR／TTS：需服务可用性、长者声音质量、成本及延迟验证；打字优先保持可用。
- 社区实时 feed、真实用户匹配、推送、社工直接发送：未验证 API 或合作方，不假定可用。MVP 可采用核验过的资料和官方报名路径。
- 公共香港记忆地图、公开故事、互助发布：未来范围；没有审核、举报、位置保护之前不发布。
- 每日问候／提醒：只在确认记忆或用户计划基础上、自愿启用后实施，排在核心记忆／社区之后。
- 团队仍需明确可信网站范围、保留期限及演示场景。活动内容由 agent 自动搜索；来源适配器和可信网站范围需要常规软件维护。对隐私默认和外发行为的需求变更按 SRS 第 18 节记录评审，不能暗改。
