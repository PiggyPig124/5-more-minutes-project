# 安心伴使用指南

适用版本：0.2（2026 年 9 月）。界面使用繁体中文，本文按页面上的按钮名称说明。

## 1. 打开与登录

本机网页预览地址为 http://127.0.0.1:8088/ ，需要本机预览服务和后端保持运行。这个地址只指向当前电脑，不是可分享给队友的公网地址。

首次使用选择「註冊」，输入称呼、电邮和密码，再选择「長者」或「照顧者」。已有账号选择「登入」。没有统一默认账号或密码。点击右上角账户图标可查看当前身份或登出。

建议为长者和照顾者分别创建账号，用两个浏览器会话或两台设备测试。不要共用同一账号模拟两种身份。

看到「示範模式」时，聊天使用预设演示回复，尚未连接真实 AI 模型。记忆管理、官方资源查询、家庭授权及消息仍可试用，但聊天表现不代表正式模型效果。

## 2. 长者：开始聊天

1. 在首页按「開始聊天」，进入对话列表。
2. 按「新對話」，输入文字并发送；也可以打开已有对话继续。
3. 安心伴提出待办事项时，先检查内容，再确认执行。确认前不会成为正式任务。

当前版本支持文字输入，尚未提供粤语语音输入、语音通话或主动晨间问候。发送失败时检查连接后重试；不要反复新建相同事项。

## 3. 保存与管理记忆

在聊天中明确说「記住：我喜歡早上飲茶」，将内容加入候选记忆。然后回到首页，打开「我的記憶」。

| 操作 | 作用 |
| --- | --- |
| 「確認保存」 | 将候选记忆确认为可在后续对话中参考的长期记忆 |
| 「修改」 | 更正内容；新版本需要重新确认 |
| 「暫停使用」 | 停止用它回答问题，可稍后恢复 |
| 「恢復使用」 | 重新启用这项记忆 |
| 「刪除」 | 删除记忆，无法通过界面恢复 |

只有属于本人、已确认且未停用的合适记忆才会参与长期召回。搜索框可查找相关已确认记忆。未配置向量服务时采用关键词检索；不相关的问题可能没有结果。

更正、停用或删除记忆会撤回相关故事和可追踪的聊天引用，避免继续使用旧内容。恢复记忆不会自动重建已撤回的故事。外部截图、导出或对方另存的副本无法由应用删除。

## 4. 整理故事卡

首页打开「故事卡」→「建立故事卡」，填写标题和故事内容，选择相关已确认记忆，再保存。故事目前由用户编写，不会自动生成传记。

分享时选择已授权的家庭成员，核对收件人及完整内容，再确认发送。没有符合权限的家庭成员时，需要先完成下面的家庭连接。删除故事会撤回通过该故事发送的关联内容；外部副本不在撤回范围内。

## 5. 连接家人

**长者操作：**

1. 打开底部「家庭」，输入照顾者注册时使用的电邮。
2. 如需互传留言，主动勾选「允許家庭訊息」。默认不勾选，照顾任务权限不会自动开放消息权限。
3. 发出邀请，将一次性邀请码交给该照顾者。

**照顾者操作：**

1. 使用相应电邮的照顾者账号登录。
2. 打开「家庭」，必要时刷新邀请列表。
3. 输入一次性邀请码，接受对应邀请。

已有连接若未包含消息权限，需要重新发出包含该权限的邀请并接受。撤销连接后，相关共享读取和新消息发送会被阻止。照顾者看不到长者的私密聊天或完整记忆库，只能访问已授权的共享内容。

## 6. 家庭留言与任务

从首页打开「家庭訊息」，选择家庭成员并输入文字。先预览，再确认发送。故事分享也采用同样的确认流程。消息到达需要刷新查看，目前没有推送通知。

「任務」页面用于查看和处理已经确认的事项。这里的确认不等于已经联系医院、成功预约或提交福利申请；当前版本不会代替你完成这些外部操作。

## 7. 查找香港生活资源

打开「生活資源」，输入需求或点击常用搜索，例如「醫療費用減免」「照顧者支援」「日間暫託」。

每张结果卡先显示名称、核实日期、官方来源入口及编号行动步骤。按「了解服務及適用條件」查看详细说明；按「申請前還需確認甚麼？」查看还需要核实的家庭或服务资料。

查询结果是申请指引，不是资格审批。申请前请打开官方来源核对最新要求。当前资料库覆盖六项经核实的官方记录，并非香港所有津贴和服务；找不到结果可缩短关键词，或直接咨询服务机构。

## 8. 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 网页打不开 | 确认本机网页服务运行在 8088 端口；换到另一台设备不能继续使用同一 localhost 地址 |
| 页面能打开但登录或查询失败 | 确认后端运行；本地网页版本连接 8012 端口，查看页面错误后重试 |
| 家庭消息没有可选收件人 | 检查邀请是否已接受，以及是否明确授予家庭消息权限 |
| 保存过的记忆没有被引用 | 检查是否仍为候选、已停用或问题不相关；修改后的记忆需再次确认 |
| 家人看不到新消息 | 刷新家庭消息页面，并检查连接是否仍有效 |
| Android 安装后连不上 | 当前测试 APK 默认连接模拟器地址 `10.0.2.2:8000`，实体手机需要使用可访问的后端地址重新构建 |

当前版本不提供自动危机报警、持续健康监测或真实预约服务。请勿把界面上的任务或演示回复当作已通知家人或服务机构。
